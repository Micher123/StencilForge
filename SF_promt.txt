StencilForge — сервис для создания трафаретных слоёв из изображений.

Реализовано:

=== Бэкенд (Go) ===
- go.mod (модуль stencilforge, зависимости от современных версий golang.org/x/image, mattn/go-sqlite3)
- main.go — HTTP сервер на :8080, middleware JWT-токенов, раздача статики frontend/dist, роутинг API
- processor/processor.go — процессинг изображений: загрузка (PNG/JPG/BMP/TIFF), K-Means кластеризация, построение слоёв, сглаживание, SVG-трассировка, ZIP-скачивание слоёв
- auth/auth.go — bcrypt хэширование, JWT токены (HS256, 72h), валидация email, проверка сложности пароля
- db/db.go — SQLite (gorm.io/driver/sqlite), миграции, CRUD пользователей и платежей, лимиты тарифов
- payment/payment.go — интеграция с ЮKassa API, создание платежа, проверка статуса
- handlers/ — HTTP хэндлеры:
  - handlers.go — загрузка изображения, генерация слоёв, скачивание слоёв
  - auth_handlers.go — регистрация, логин, получение профиля, выход
  - payment_handlers.go — список тарифов, создание платежа, вебхук ЮKassa, проверка статуса

=== Фронтенд (React + TypeScript) ===
- package.json, tsconfig.json, webpack.config.js
- App.tsx — главный SPA с роутингом (react-router): главная страница, страница авторизации, профиль
- Компоненты:
  - UploadZone.tsx — загрузка изображения (drag-n-drop / выбор файла), валидация форматов и размера
  - LayersPanel.tsx — отображение сгенерированных слоёв (preview)
  - AuthPage.tsx — форма регистрации и входа
  - ProfilePage.tsx — профиль пользователя со сменой тарифа (платежи)
  - ThemeToggle.tsx — переключение светлой/тёмной темы
- utils/errors.ts — утилита extractErrorMessage для парсинга JSON-ошибок от API
- styles/global.css — глобальные стили с CSS-переменными для тем

=== Сборка и деплой ===
- Makefile — сборка фронтенда и бэкенда
- deploy.sh — скрипт развёртывания
- .env.exemple — пример переменных окружения
- .env — реальные переменные окружения
- .gitignore — игнорирование node_modules, .env, dist
