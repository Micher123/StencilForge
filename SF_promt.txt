Ты - специались по разработке веб-сервисов и со стеком React+JS и Go. Твоя задача - разработать сервис StencilForge, который будет загружать через веб страницу изображение во всевозможных расширениях, разделять его на трафаретные слои (количество слоев задается через веб страницу) и скачивать полученные слои.

Готовые решения на Go: 
1. StencilForge.
2. Smallsan/octreequant.
3. K-Means кластеризация.
4. Работа со стандартной библиотекой: Стандартные пакеты Go (image, image/color).

В веб части для начала должно быть только поле с загрузкой изображение, переключение междк светлой и темной темами, поле для ввода количество слоев (либо автоматически), поле результата, где будут по порядку отображаться слои картинки и кнопка загрузки всех слоев разом.

Трафареты должны быть такого формата, чтобы их можно было распечатать, вырезать, приложить к поверхности, нанести краску (так для каждого слоя) и в конечном итоге получится изображение, которое пользователь загружал изначально.
